05 — Recommended safe sequence

How to actually get there

  1. Close coverage the proven way. Continue the additive non-default TermDefined scale-out for remaining gaps — this replaces Phase 1's default-flip, which is impossible-as-scoped and unnecessary.
  2. Build + parity-prove native pricing in a sandbox while the custom stack stays fully deployed. Author policies, backfill PricingSource, wire QLI uplift, green-parity vs COLA per currency/partner/out-year.
  3. Re-author the procedure in a NEW version to use native uplift, parity-green. Only then delete the COLA-specific branches — strictly last, never PartnerNetPricePosthook wholesale.
  4. Phase 3 by deactivation, not deletion. Prove per-SKU coverage, exclude new-business + constraint rules, preserve carryover-cleanup, runtime-confirm flows/engines, soak a full cycle, then remove.
  5. Drop the false-premise steps. No "blank Order.Type" fix; keep Renewal_Status__c as the succession signal; no Contract.Status write without a sandbox no-fault proof.
  6. Remediate the backlog by re-provisioning the 757 Draft quotes (born-net Renew + TermDefined) — never mass-reprice, never touch the 982 Approved / 30 Won / 208 ordered.
