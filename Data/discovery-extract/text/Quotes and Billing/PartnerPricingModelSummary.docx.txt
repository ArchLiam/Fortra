Partner Pricing Model Setup & Configuration
Partner Managers configure the available pricing models for each partner account:
They can enable one or both models: Guaranteed Margin Model and Discount Model.
If only one model is enabled, it automatically becomes the default.
If both models are enabled, the Partner Manager selects which model will be the default model for that account.
Partner Managers can update or change the pricing model configuration as needed.
Partner Pricing Model Quoting
When a billing partner is added to a quote, the default pricing model from that partner’s account is automatically set on the quote. If the partner account supports both the Guaranteed Margin and Discount models, the user can choose which model to apply for the quote. The selected model determines how partner margins or discounts are calculated for the quote, and users can switch between models if both are available for the billing partner.
