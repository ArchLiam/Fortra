## R-3 — Trigger-event matrix (the reporter's "confirm the events" ask)

| AssetAction `CategoryEnum` | Re-derive description? | Rationale |
|---|---|---|
| Initial Sale | ✅ | asset birth |
| Upsells | ✅ | changes what was purchased |
| Renewals | ✅ | renewal of the purchased item |
| Downsells | ✅ | changes tier/qty |
| Upgrades | ✅ | changes tier/config |
| Downgrades | ✅ | changes tier/config |
| Swaps | ✅ | changes the product |
| Cross-Sells | ✅ | adds/changes purchased product |
| Terms And Conditions Changes | ❌ | changes terms, **not** the product line |
| Transfers | ❌ | moves account; product unchanged |
| Cancellations | ❌ | removes; nothing purchased to describe |
| Other | ❌ | undefined catch-all; not a product change |
| **Manual field edit on the Asset** | ❌ **out of scope** | creates no AssetAction; a manual edit is user-intentional and must not be auto-reverted from an order line (owner decision, R-3) |
