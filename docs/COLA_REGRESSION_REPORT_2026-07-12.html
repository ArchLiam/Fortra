13MyCAP approval trigger out-year < 3% floor → Mycap__c=true → MYCAP_Approval__c=truePASS

On the non-prepaid qualifying line m4AE, set COLA_Outyear_Uplift_Percent__c=2 (< 3 floor), reprice ×2. Debug log & oracle:

The async MyCAPFlagApplier queueable flips Mycap__c=true; the record-triggered approval flow then sets MYCAP_Approval__c=true → Deal Desk routing. Floor = MyCAP_Rules__mdt.Global.Minimum_Out_Year_Uplift_Percent__c = 3.

Edge-case caveat (ticket-worthy, not a fail of this scenario): the alternate lever — overriding year-1 COLA% below floor — did not flag the quote when the line's Default_COLA_Uplift_Percent__c is null. The flag method's override-detection is isOverridden || (currentUplift != null && persistedDefault != null && currentUplift != persistedDefault); the persistedDefault != null guard short-circuits on the null default, so the override is missed and the line is treated as MyCAP-default (3%, meets floor). The canonical out-year mechanism works; this narrow year-1-override path does not. The pricing engine does detect the same override (net was correct), so the two override-detectors are inconsistent.
