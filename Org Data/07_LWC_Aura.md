# 07 — LWC & Aura Components

## Overview

This doc covers the **23 custom Lightning Web Components (LWC)** and **8 Aura bundles** in the Fortra Salesforce org. The LWCs cluster into a few domains: **quote authoring/pricing** (RLM Revenue Cloud quote UX), **hardware configuration** (the Power/Tech-catalog hardware-pricing flow), **data migration tooling** (admin-only Tabs that drive Apex batch migrations of legacy Quotes/Orders into RCA), **document generation** (OmniStudio/DocGen wrappers for the Quote PDF + DocuSign flow), **partner/portal community** UI, **operations/checklist** panels, and **licensing/key generation**. The Aura bundles are almost entirely **Experience Cloud (community) login/registration** scaffolding plus a handful of generic Flow utility actions (toast, navigate, refresh).

Key patterns to know:
- Most data-bearing LWCs are thin views over an Apex `*Controller` / `*Helper` / `*Service` class (named in the Purpose column) — start there when tracing logic.
- **Migration tools** (`quoteMigrationTool`, `orderMigrationTool`, `quoteMigrationTool`, `rcaProductCreator`) are admin Tab utilities that kick off Apex Batch/Queueable jobs and poll status; they are not part of the runtime sales flow.
- **OmniStudio DocGen** components (`documentGenerationQuoteEnglish`, `docGenerationSampleFndSingleDocxLwcEnglish`) are **auto-generated by the Vlocity/OmniStudio compiler** (`*_def.js`, `*_nds.*` files) — do not hand-edit; regenerate from the OmniScript. `fortraQuoteOsCard` and `docGenOmniScriotWrapperLWC` are the hand-written custom pieces of that flow. See the *DocGen Quote PDF pipeline* memory.
- Several components target `lightning__FlowScreen` or `lightning__RecordAction` (ScreenAction/Action quick actions) rather than being placed on a page — check the **Targets** column before assuming where a component renders.

## Quote authoring & pricing

| Component | Type | Targets | Purpose |
|---|---|---|---|
| `quoteLineFlexPanel` | LWC | RecordPage (Quote), AppPage, HomePage, Community, Tab | Header panel on the Quote Lines tab. Shows/edits Currency, Start Date, header discount fields (`Header_Discount_Value__c`, `Manual_Discount__c`, distribution logic/type) and Subtotal; triggers reprice via `QuoteRepricingController.repriceQuote` and polls `isQuoteAvailable` for the RLM lock. | `quoteCloneModal` | LWC | RecordAction (ScreenAction, Quote), RecordPage | Quick-action modal to clone a Quote with options (copy lines, recalc pricing, copy discounts, make primary, notes). Backed by `QuoteCloneService.cloneQuoteWithLines`; navigates to the new Quote. |
| `operationsChecklistPanel` | LWC | RecordPage (Quote), AppPage, HomePage | Internal operations checklist on the Quote with completion %, edit-permission gating, expandable items. Backed by `OperationsChecklistController` (`getChecklistItems` / `updateChecklistItem`). |

## Hardware configuration

These drive the Power/Tech-catalog hardware-pricing workflow (see the `Hardware__c` object and `HardwarePreConfigInvocable`). Authored largely by Marc DeBrey.

| Component | Type | Targets | Purpose |
|---|---|---|---|
| `hardwareDefaultsApplicator` | LWC | FlowScreen, RecordPage, Community | Displays hardware config defaults (pGroup, Server Type, Users Per Partition) inside the Product Configurator; gated to Tech-catalog / Power-category products via `HardwarePreConfigInvocable.isProductHardwarePricingApplicable`. Takes `transactionId`/`groupId`/`productId` from configurator context. |
| `hardwareGroupManager` | LWC | RecordAction (Action quick action) | Unified modal to **create / edit hardware groups and assign hardware** in Revenue Cloud (3 modes). Backed by `HardwareGroupController` + `HardwarePreConfigInvocable`. `recordId` = Quote. |
| `hardwareManagementModal` | LWC | **Not exposed** (`isExposed=false`) | `LightningModal` child for linking hardware references to selected quote lines or flagging lines as needing new hardware. Backed by `HardwareManagementController`. Launched programmatically, not placed on a page. |

## Data migration tooling (admin Tabs)

Admin-only utilities that orchestrate Apex batch migrations of legacy data into RCA / Revenue Cloud. Each is a `lightning__Tab` shell over a heavyweight `*MigrationController` / `*Controller` Apex class (gap analysis, start/abort batch, poll status). **Not part of the live sales flow.**

| Component | Type | Targets | Purpose |
|---|---|---|---|
| `quoteMigrationTool` | LWC | Tab | Populates Revenue Cloud fields on migrated Quotes & QuoteLineItems (default filter `DY_%`); optional Q2O prep, reprice, and attribute load. Backed by `QuoteMigrationController`. |
| `orderMigrationTool` | LWC | Tab | Creates Orders directly from migrated Quotes via the PST (Place-Sales-Transaction) API; rich UI for pricebook selection, saved filters/presets, coverage analysis, run-detail buckets, re-run queue, and cleanup jobs. Backed by `OrderMigrationController`. The largest/most feature-dense migration tool. |
| `rcaProductCreator` | LWC | AppPage, HomePage, Tab, UtilityBar | Bulk **technical-product** creation for RCA: CSV/spreadsheet upload, validation, catalog-tree browsing, bundle support; links technical products to commercial via `ProductFulfillmentDecompRule`. Backed by `RCATechnicalProductController` + `RCACatalogTreeController`. (Coastal — Fortra RCA Migration.) |
| `contextDefinitionDependencyManager` | LWC | AppPage, RecordPage (ContextDefinition), HomePage, Tab | Admin tool to **bulk deactivate/reactivate Context Definition dependencies** (Expression Sets & versions, RLM 2026 Rule Library Versions, Decision Tables) and validate fields. Backed by `ContextDefinitionManager` + `ContextDefinitionFieldValidator`. Load-bearing for the RCA pricing/context rework — relates to the "contextDefinitionName" reprice-gack and pricing-procedure version issues in memory. |

## Document generation (OmniStudio / DocGen)

The Quote PDF + DocuSign send flow. See the *DocGen Quote PDF pipeline* memory. `*_def.js` / `*_nds.*` files are **OmniStudio-compiler output — regenerate, don't hand-edit.**

| Component | Type | Targets | Purpose |
|---|---|---|---|
| `documentGenerationQuoteEnglish` | LWC | Community Page/Default, RecordPage, AppPage, HomePage | **Auto-generated** OmniScript runtime LWC for `DocumentGeneration/Quote/English` (the production Quote document-generation OmniScript). `runtimeNamespace=omnistudio`. |
| `docGenerationSampleFndSingleDocxLwcEnglish` | LWC | Community Page/Default, RecordPage, AppPage, HomePage | **Auto-generated** OmniScript runtime LWC for the sample single-DOCX FND DocGen flow. `runtimeNamespace=omnistudio`. Likely a reference/sample, not the live Quote path. |
| `docGenOmniScriotWrapperLWC` | LWC | RecordAction (ScreenAction), RecordPage | Hand-written wrapper that launches the Quote DocGen OmniScript with prefill (`ContextId`/`ObjectId`/`QuoteId` = recordId) and widens the modal to 90vw. `runtimeNamespace=omnistudio`. (Note the misspelled "Scriot" in the bundle name.) Author: Liam Jeong. |
| `fortraQuoteOsCard` | LWC | AppPage, RecordPage | Hand-written multi-variant card used **inside** the Quote DocGen OmniScript (`variant` = step1 / step2 / confirmation). Replaces OmniScript Text Blocks to bypass the managed-package sanitizer that strips styled HTML with merge fields. Sub-templates: `...Step1/Step2/Confirm.html`. |

## Aura bundles

The Aura set is dominated by **Experience Cloud login/registration** components (the standard Salesforce community auth scaffolding, lightly customized) plus generic Flow/quick-action utilities. The two `.evt` bundles are application events that pass branding/start-URL context between the community auth components.

### Experience Cloud authentication

| Component | Type | Purpose |
|---|---|---|
| `loginForm` | Aura cmp | Community login form (username/password). Controller `LightningLoginFormController`; supports self-registration & forgot-password links, branding `expid`, post-login `startUrl`. |
| `forgotPassword` | Aura cmp | Community password-reset form. Controller `LightningForgotPasswordController`; handles `setExpId` event for branding. |
| `selfRegister` | Aura cmp | Community self-registration form (name/email/optional password + field-set extra fields). Controller `LightningSelfRegisterController`; registers `setStartUrl` event. |
| `setExpId` | Aura evt | APPLICATION event carrying the branding experience id (`expid`) into the auth components. |
| `setStartUrl` | Aura evt | APPLICATION event carrying the post-login `startURL` (Map) into the auth components. |

### Flow / quick-action utilities

| Component | Type | Purpose |
|---|---|---|
| `navigateToRecord` | Aura cmp | `force:lightningQuickAction` + `availableForFlowActions`: navigate to a record by `recordId`. Aura twin of `navigateToRecordLWC`. |
| `RefreshPage` | Aura cmp | `availableForFlowActions` action to refresh the record page after a Screen Flow completes (place at end of flow). |
| `showToast` | Aura cmp | `availableForFlowActions` action to fire a configurable toast (type/title/message/icon/mode/duration, clickable URL in message). Third-party origin (Eric Smith / Salesforce BSD-licensed), v2.0. |
